# Modelos

`python src/restaurar_archivos.py` prepara los tres modelos de referencia verificados de la última entrega. `python src/pipeline.py --stage all` los vuelve a entrenar y reemplaza estos resultados.

Usa el entorno indicado en la guía; los archivos joblib dependen de las versiones de las bibliotecas. Las métricas están en `evidencias/metricas.json`.
